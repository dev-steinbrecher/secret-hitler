# Secret Hitler Print & Cut Assets

This repository contains PNG assets for the board game **Secret Hitler**, along with the original **Silhouette Studio (.studio3)** files optimized for **Print & Cut** workflows using Silhouette Cameo cutters.

## Contents

* PNG files for game components, cards, tokens, and other printable assets
* Silhouette Studio project files ready for Print & Cut
* Layouts optimized for Silhouette Cameo cutting machines
* Files prepared for easy home printing and production

## Usage

Print the PNG assets or open the included Silhouette Studio files directly in Silhouette Studio software to print and cut game components with compatible Silhouette Cameo devices.
